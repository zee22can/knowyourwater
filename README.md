# Know Your Water

A water literacy programme website for Canada: learning modules, a school quiz league and a sample quiz, with an animated flowing-water background.

The whole site is one file, `index.html`. It needs no build step and no other files.

## Publish with GitHub Pages

1. Put `index.html` in the root of the repository.
2. Open Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then save.
4. The site appears at `https://<your-username>.github.io/<repository-name>/` after about a minute.

## Edit the quiz

Questions are in the `Q` list near the bottom of `index.html`.
